What was verified

  • schema_version returns 1 on the policy engine contract.
  • admin returns the configured multi-sig admin public key.
  • Direct payments under the spend cap settle atomically in under 12,000 stroops.
  • Transactions exceeding the spend cap are automatically diverted into the on-chain escrow vault.
  • Payments involving denylisted accounts are deterministically rejected with error code 1002 (PAYMENT_DENIED).
  • Canonical 270 error codes catalog verified across contracts, SDK, and dashboard.

Reproduce it

# Clone and test the contracts workspace
git clone https://github.com/Safeguard-Inc/safeguard-contracts
cd safeguard-contracts

# Run all unit tests, contract host simulations, and gas benchmarks
cargo test --workspace

# Deploy to Testnet using the automated deployment script
STELLAR_ADMIN=safeguard-admin bash scripts/deploy-testnet.sh
Open in Live Console View on StellarExpert
