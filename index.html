The problem

Modern payment flows and tokenized assets on Stellar need robust compliance guarantees: institutional operations require policy contracts, allow/block-list identity registries, account freezing, spend caps, and escrow mediation across standard SEP-41 SAC tokens today, with forward compatibility for emerging Soroban confidential token standards.

What was missing was a unified, non-custodial layer connecting those primitives to actual deployments. Safeguard provides the complete four-tier architecture: smart contracts, SDK pre-flight simulation, operator console, and developer documentation.

Four-tier architecture, one unified pipeline

Strict separation of duties across four specialized repositories with 10-check automated CI/CD.

Why it is different

Pure, deterministic evaluation

The decision engine is a pure function: (request, policy) → (decision, reason, rule_id). No side effects, no ambient state, no surprise branches.

Ultra-low gas footprint

Optimized for minimal CPU and memory consumption on Soroban. Direct payment settlements execute in under 12,000 stroops of gas.

270 cataloged error codes

Canonical error code taxonomy across all four tiers ensures every failure, revert, or flag is uniquely identifiable and instantly actionable.

Quickstart

# 1. Smart Contracts — build and test Soroban policy & escrow payment contracts
git clone https://github.com/Safeguard-Inc/safeguard-contracts
cd safeguard-contracts && cargo test --workspace

# 2. Backend & SDK — test pre-flight simulation and 270 error codes catalog
git clone https://github.com/Safeguard-Inc/safeguard-backend
cd safeguard-backend && npm test

# 3. Web Dashboard — run the Next.js 14 operator console locally
git clone https://github.com/Safeguard-Inc/safeguard-dashboard
cd safeguard-dashboard && npm install && npm run dev
